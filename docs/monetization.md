# 収益化戦略

## なぜ「AI習慣化・セルフケア」か

- ヘルスケア&フィットネスはApp Storeでサブスク課金率が最も高いカテゴリの一つ
- 習慣化アプリは**継続利用が前提**のためLTVが伸びやすく、サブスクと相性が良い
- AIパーソナルコーチは差別化要因かつ「無制限化」がそのまま課金理由になる
- 日本市場はARPUが高く、英語圏大手(Fabulous, Headspace等)のローカライズが弱い隙間がある

## 価格設計

| プラン | 価格 | 備考 |
|---|---|---|
| 月額 | ¥480 | コーヒー1杯の価格帯。心理的ハードルが低い |
| 年額 | ¥3,800 | 月額比 約34%オフ。LTV確保の主力。ペイウォールでデフォルト選択 |
| (将来) 7日間無料トライアル | ¥0→年額 | 転換率が安定してから導入 |

## フリーミアム設計(実装済み)

| レバー | 無料の上限 | 課金動機 |
|---|---|---|
| 習慣数 | 3つ | 生活全体を管理したくなった時点で上限に当たる |
| AIコーチ | 5通/日 | 会話が盛り上がった瞬間に上限が来る=最も熱量が高い瞬間にペイウォール表示 |

ポイント: 無料でも「毎日使う理由」(チェックイン・ストリーク)を残し、DAUを維持したままアップセルする。

## ユニットエコノミクス(概算)

- AIコーチ原価: 1通あたり入力~2K tokens / 出力~300 tokens 想定
- 無料ユーザー上限 5通/日 → 原価は月数十円程度に制御可能
- プレミアム(¥480/月)ユーザーがヘビーに使っても粗利は十分確保できる
- 対策済み: 履歴は直近20通のみ送信 / max_tokens 1024 / サーバー側で共有トークン認証
