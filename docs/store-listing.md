## 詳細な説明

```text
■ ココロコーチとは
習慣と気分を毎日記録するだけで、その日だけの「一輪の花」が咲きます。
達成した習慣の数が花びらに、その日の気分が花の色に。
同じ日は二度となく、二つとして同じ花は咲きません。
咲いた花は一週間で「こころの庭」になり、AIがあなたの「パターン」を発見します。

■ 主な機能
・今日の一輪:習慣を達成するたび花びらがひらく。記録が生成アートになる
・こころの庭:一週間・ひと月の記録が花畑に。育てる楽しさが続く理由になる
・習慣トラッキング:タップひとつでチェックイン。連続日数（ストリーク）を記録
・きょうの空模様:1日5秒、雨〜快晴のアイコンで気分を記録
・週間/月間レポート:達成率・気分の推移・ベスト習慣をまとめて確認
・AIインサイト:気分×習慣の相関・曜日別パターンをAIが自動分析
・年間レポート:一年の庭をふりかえる
・AIコーチ:「やる気が出ない」「続けるコツは?」に24時間いつでも相談
・シェア:今日の一輪は短冊風カードに。庭も達成記念もそのままSNSへ

■ こんな方におすすめ
・三日坊主を卒業したい
・ストレスケアや生活リズムを整えたい
・日記やセルフケアアプリが続かなかった
・自分のパターンを知って、もっとうまく生きたい

■ プレミアム（サブスクリプション）
・習慣を無制限に登録（無料: 3つまで）
・AIコーチと無制限にチャット（無料: 5通/日）
・気分×習慣の相関分析・曜日別パターン分析
・広告非表示
月額480円 / 年額3,800円（7日間無料体験あり）
無料でも毎日お使いいただけます。

※本アプリは医療行為・診断・治療を提供するものではありません。

【自動更新サブスクリプションについて】
・料金はGoogle Playアカウントに請求されます
・期間終了の24時間前までに解約しない限り自動更新されます
・購入後はGoogle Playのアカウント設定から管理・解約できます
利用規約: https://kokorocoach.pages.dev/terms
プライバシーポリシー: https://kokorocoach.pages.dev/privacy
```

## ストア素材（生成済み → `store-assets/`）

`node scripts/generate-store-assets.mjs --shots` で再生成できる
（スクリーンショットは `npx expo start --web --port 8090` を起動してから）。

| ファイル | 用途 | サイズ |
| --- | --- | --- |
| `store-assets/feature-graphic.png` | Feature Graphic | 1024×500 |
| `store-assets/screenshot-1-today.png` | 今日の一輪（満開） | 1080×1920 (9:16) |
| `store-assets/screenshot-2-share.png` | 短冊シェアカード | 1080×1920 |
| `store-assets/screenshot-3-garden.png` | 今週の庭 | 1080×1920 |
| `store-assets/screenshot-4-coach.png` | AIコーチ | 1080×1920 |
| `store-assets/screenshot-5-tree.png` | ここロコーチの木・サマリー | 1080×1920 |

アプリアイコンは `node scripts/generate-icons.mjs` で `assets/images/` に生成済み
（Playコンソールには `assets/images/icon.png` 1024×1024 を登録）。

掲載時のキャッチコピー案:
1. 今日の一輪 — 「毎日の記録が、一輪の花になる」
2. シェアカード — 「今日の一輪を、そのままSNSへ」
3. 庭 — 「一週間で、こころの庭が育つ」
4. コーチ — 「24時間いつでも相談できる」
5. 木 — 「続けた日々が、木を育てる」

※ ペイウォール以外の画面で構成すること（課金画面のスクショは非推奨）
